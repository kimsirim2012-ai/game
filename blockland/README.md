# Blockland · 도구와 전투 모험판 (4차)

이 폴더의 **Blockland.html**을 내려받아 Chrome/Edge에서 열고 **세상에 들어가기**를 누르세요. 저장소 전체는 Code → Download ZIP으로 받을 수 있습니다. 인터넷·설치·서버 없이 실행하는 단일 HTML 게임입니다.

이번 업데이트는 요청한 **1~4단계: 기존 분석·버그 수정 → 기본 도구 → 드롭·채집·제작 → 기본 전투·몬스터**를 구현합니다. 기존 청크 월드, 지형, 동물 9종, 주민 대화, 꽃, 건축, 물리와 저장 기능을 재사용했습니다.

낮·밤 조정: **낮 17분 + 밤 4분 = 하루 21분**입니다. 일출·일몰을 부드럽게 전환하고, 화면의 하늘 밝기와 지하 음영을 몬스터 생성 판단에도 사용합니다. 기존 저장의 시각과 메뉴 일시정지는 유지합니다. 변경·검증 기록은 DAY-CYCLE.md를 참고하세요.

## 처음 시작하기

통나무를 좌클릭으로 꾹 눌러 캐고, 떨어진 아이템에 다가가 수집하세요. **E → 판자 → 막대기·제작대**를 만드세요. 제작대를 핫바로 옮겨 우클릭으로 설치하고 약 4블록 안에 있으면 E의 도구 제작법이 활성화됩니다.

나무 곡괭이로 돌을 캐서 조약돌과 돌 도구를 만드세요. 석탄과 철 원석을 채굴하고, 제작·설치한 화로를 우클릭해 철괴를 제련하세요. 철 곡괭이 이상으로 다이아몬드를 얻습니다. 옛 64×64 지역은 보존되므로 이전 저장에서는 바깥 지역의 지하에서 새 광석을 찾으세요.

**이전 버전 저장은 창작 모드로 이어집니다.** Esc 메뉴의 **플레이 방식 → 모험**을 선택하면 유한 아이템 채집·제작·전투를 사용할 수 있습니다. 창작 모드의 기존 무제한 블록 선택도 유지됩니다. 모드 전환은 인벤토리를 삭제하지 않습니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD / 마우스 | 이동 / 시점 |
| Space / Shift | 점프·수영·비행 상승 / 웅크리기·물속 하강 |
| W 두 번 | 달리기 |
| Ctrl+W | 전체 화면에서 Keyboard Lock이 허용된 경우 달리기. 창 모드에서는 탭 닫기와 충돌하므로 W 두 번 권장 |
| 1~9 / 휠 | 핫바 선택 |
| 좌클릭 유지 | 시간에 따른 채굴 / 조준한 동물·몬스터 공격 |
| 우클릭 | 가진 블록 설치 / 제작대·화로 열기 / 도구 사용 |
| 활을 들고 우클릭 유지 → 놓기 | 활 당기기 → 화살 발사 (화살 필요) |
| E | 인벤토리·제작 / 닫기 |
| 인벤토리 클릭 두 번 / 드래그 | 아이템 이동·교환 |
| 아이템 선택 후 다른 칸 우클릭 | 절반 이동 |
| Shift+클릭 | 가방 ↔ 핫바 빠른 이동 |
| G (게임 중) | 선택한 핫바 아이템 한 개 버리기 |
| E의 방패 버튼 | 선택한 방패를 보조 손에 장착·해제 |
| 방패 장착 후 빈손·검·도구로 우클릭 유지 | 정면 방어 (활·낚싯대·설치 아이템은 해당 사용 동작 우선) |
| T / 주민 우클릭 | 기존 주민 대화 |
| F / Q | 기존 비행 전환 / 비행 하강 |
| R / Esc / F3 | 시작 지점 복귀 / 메뉴 / 성능 진단 |

모험 모드에도 기존 F 비행과 R 복귀를 남겨 두었습니다. 강제 생존 규칙이 적용된 완전한 생존 모드는 아닙니다.

## 구현 범위와 한계

- 나무·돌·철·다이아몬드 곡괭이·도끼·삽·괭이·검, 내구도·파손·채굴 등급, 가위·낚싯대.
- 9칸 핫바+27칸 가방, 스택, 바닥 드롭·근접 수집, 재료를 소비하는 제작법 목록, 제작대, 철 제련 화로.
- 쿨다운 근접 공격·넉백·체력·전리품, 활 장전·화살 궤적·충돌, 방향에 따른 방패 방어, 1인칭 장비·채굴 균열·효과음·파티클.
- 밤·지하 생성 조건, 좀비·스켈레톤·크리퍼·거미와 서로 다른 공격. 몬스터 최대 12, 전체 개체 최대 76.
- 전투 체력 20, 사망·소지품 드롭·리스폰. 허기·음식 섭취·낙하·익사·갑옷·경험치는 후속 단계입니다.

제작은 재료를 자동으로 배치하는 **제작법 목록 방식**입니다. 수동 2×2/3×3 제작 격자는 아직 없습니다. 화로는 석탄 1개로 철 원석 최대 8개를 한 묶음으로 제련합니다. 괭이는 경작지까지 만들며 작물 재배는 후속 작업입니다. 도구 수치·AI·그래픽은 자체 구현으로 Java Edition과 완전히 같지는 않습니다.

## 저장과 설정

IndexedDB에 월드 변경·위치·시간·인벤토리·내구도·보조 손·바닥 아이템·화로 진행·주변 살아 있는 몬스터의 위치와 체력을 저장합니다. 전투 애니메이션, 날아가는 화살과 파티클은 저장하지 않습니다. 동물·주민의 장기 개체 상태 저장은 아직 없습니다.

v1/v2 JSON과 기존 브라우저 저장을 읽습니다. v3는 별도 키로 저장해 옛 버전 탭이 새 인벤토리를 덮어쓰지 않게 했습니다. 메뉴의 **세상 파일 저장/파일 불러오기**로 JSON 백업을 만드세요. 다른 브라우저·파일 위치에서는 브라우저 저장이 분리될 수 있으므로 JSON으로 옮기세요. 새 세상은 현재 슬롯을 교체하므로 먼저 파일로 저장하세요.

렌더 거리는 48~128m이며 느리면 48~64m로 줄이세요. 측정 환경·결과는 **UPDATE4.md**와 **tests/performance-results.json**에 있습니다. 모든 PC·전투·빠른 탐험에서 60FPS를 보장하는 수치는 아닙니다.

## 소스·검증

`node build.cjs`로 src 모듈과 템플릿을 합쳐 Blockland.html을 만듭니다. 실행 파일에는 외부 라이브러리나 네트워크 의존성이 없습니다.

```powershell
node --test tests/physics.test.cjs tests/world.test.cjs tests/ecosystem.test.cjs tests/items.test.cjs tests/adventure.test.cjs
node tests/browser.cjs
node tests/exploration-browser.cjs
node tests/update4-browser.cjs
node tests/update4-ui-storage.cjs
node tests/performance.cjs
node --test tests/day-cycle.test.cjs
node tests/day-cycle-browser.cjs
```

브라우저 검사는 Chrome과 Playwright가 필요합니다. 모듈 위치가 다르면 PLAYWRIGHT_PATH를 지정하세요. 수정 내용·테스트 범위·5~10단계 후속 계획은 **UPDATE4.md**에 있습니다. EXPLORATION.md는 3차, DEVELOPMENT.md는 그 이전 물리 개선의 기록입니다.


## 개발 환경

Node.js에서 `npm install` 후 `npm run build`로 실행 파일을 재생성하고 `npm test`로 단위 검사를 실행합니다. 브라우저 검사는 Chrome이 필요하며 `npm run test:day-cycle` 또는 `npm run test:combat`으로 실행합니다.
