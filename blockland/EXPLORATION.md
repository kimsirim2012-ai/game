# 야생과 마을 탐험 업데이트 — 2026-10-17

이번 변경은 기존 WebGL 엔진, 픽셀 아틀라스, 청크 메시, DDA 선택, 고정 시간 물리, 조작과 파일 실행 방식을 확장한 것입니다. 엔진을 교체하거나 기존 게임을 삭제하지 않았습니다.

## 월드와 지형

- 고정 64×64 수평 경계를 제거했습니다. 16×16×112 복셀 청크를 플레이어 중심으로 생성합니다. 실용 좌표 범위는 X/Z ±1,000,000블록입니다.
- 시드 기반 개선된 격자 노이즈(5차 보간)와 여러 주파수의 fBm, 능선 함수, 대륙/강/호수 필드를 조합했습니다. 평야, 구릉, 산악/설산, 강과 계곡, 바다/해변, 사막/모래언덕, 숲, 꽃 초원과 동굴이 생성됩니다. 지형 높이 및 강·마을 주변의 높이 전환을 보간합니다. 재료 전환은 블록 단위입니다.
- 생성 데이터는 청크별 Uint8Array입니다. 지역 생성은 행 단위 generator로 나누고, 가까운 청크부터 한 프레임 약 2.5ms씩 처리합니다. 메시 생성도 별도 약 2.5ms 작업 예산으로 나눕니다. 최초/불러오기 주변 3×3은 충돌 안전을 위해 먼저 준비합니다.
- 먼 청크의 CPU 복셀 배열과 GPU 버퍼를 제거합니다. 노이즈 열 캐시와 마을 캐시도 상한을 둡니다. 블록 편집 기록은 생성 데이터와 분리하여 언로드 후에도 유지합니다.
- 렌더 반경은 3/4/5/6/8청크(48/64/80/96/128m)로 선택할 수 있습니다. 기본값은 5입니다. 반경보다 한 청크 더 먼 영역까지 보존해 경계 이동 시 재생성을 줄입니다.
- 이웃 면 제거, Frustum Culling과 뒷면 제거를 유지합니다. 청크 경계에서 인접 지역이 생성되면 양쪽 메시를 다시 요청합니다. 미완료 지역의 충돌은 결정적인 지형 조회로 보호합니다.

## 식물과 나무

- 민들레, 양귀비, 데이지, 튤립, 해바라기, 장미 덤불, 키 큰 풀, 작은 풀, 양치식물, 버섯을 추가했습니다. 사막에는 선인장도 생성됩니다.
- 투명 픽셀 스프라이트를 교차 평면으로 표현하고, 청크의 단일 메시로 묶습니다. 식물마다 Draw Call을 만들지 않습니다. Three.js의 InstancedMesh를 사용하는 대신 기존 WebGL의 청크 배치 방식을 사용합니다.
- 식물 상단은 셰이더에서 바람에 흔들립니다. 꽃/식물을 왼쪽 클릭해 채집하면 E 선택창의 수집 목록에 수량이 나타나며 저장됩니다.
- 참나무/자작나무/침엽수를 바이옴별로 배치하며 높이와 수관 모양이 달라집니다. 식물 텍스처와 엔티티 색상은 코드로 만든 자체 아틀라스이며 Nearest Filtering을 사용합니다.

## 동물과 주민

- 소, 돼지, 양, 닭, 말, 토끼, 늑대, 여우, 물고기 9종을 구현했습니다. 몸통·머리·다리·귀·꼬리·뿔/부리/갈기/지느러미를 종별로 구성했습니다.
- 배회/둘러보기/풀 뜯기, 플레이어 쳐다보기, 토끼·여우·닭·말의 도망 행동, 교대 다리 동작과 꼬리/날개 움직임이 있습니다. 물고기는 물속을 이동합니다.
- 기존 물리 모듈을 개체별 크기와 속도로 재사용합니다. 벽을 감지해 방향을 바꾸고 한 블록 경사에서는 점프를 시도합니다. 이는 로컬 장애물 회피이며 장거리 길찾기 시스템은 아닙니다.
- 동물과 주민을 합쳐 최대 76마리/명으로 제한합니다. 주민을 위한 자리를 남겨 둡니다. 약 25m 이내는 20Hz, 중간 거리는 약 8Hz, 먼 거리는 4Hz로 AI를 갱신합니다. 모델은 가까운 개체만 30Hz 배치 갱신합니다.
- 시드가 정한 마을에 빈 내부 공간·창문·출입구·지붕을 갖춘 집 4채와 길/집 앞 연결로가 생성됩니다. 마을마다 이름이 있으며 주민 4명은 이름·의상·머리/장식이 다릅니다.
- 주민은 마을 길의 경유점을 따라 이동하며 가까이 다가가면 바라봅니다. T 또는 바라보는 주민을 우클릭하면 실제 대화창이 열립니다. 대사는 각 주민에게 지정한 안내 문구입니다.

## 하늘·물·소리

- 저장되는 20분 낮밤 주기, 움직이는 태양과 달, 일출/일몰 하늘색과 세계 밝기, 이동하는 블록 구름이 있습니다.
- 숲/설산/사막/수중에서 안개 거리와 색이 달라집니다. 지하 면은 지표에서의 깊이에 따라 어두워집니다. 실시간 전역 조명/그림자맵은 사용하지 않습니다.
- 물과 유리는 별도 투명 패스로 그립니다. 수면의 정점은 셰이더로 움직이며 물속에서도 표면을 볼 수 있습니다. 유체 유동 시뮬레이션은 없습니다.
- Web Audio로 생성한 바람·물가 소리와 새소리를 제공합니다. 숲과 평야/물가의 필터/음량이 다릅니다. 메뉴의 자연 소리 옵션으로 끌 수 있습니다. 음원 파일을 다운로드하지 않습니다.

## 저장 호환성과 남은 한계

- v2 월드 데이터에 시드, 기존 지역 보존 여부, 청크별 편집 기록, 위치/시점, 비행/핫바, 월드 시간, 렌더 반경과 식물 수집량을 기록합니다. IndexedDB가 기본이며 작은 복구 스냅샷은 localStorage에도 저장합니다.
- 예전 `blockland.offline.v1` 키는 삭제하지 않습니다. 새 v2 저장이 없으면 기존 저장을 가져옵니다. 원래 64×36×64 지역은 원본 스냅샷과 바이트 단위로 일치하도록 유지하고, 바깥 지형의 높이를 연결합니다. 옛 JSON 파일도 불러올 수 있습니다.
- 기존 세상으로 이어서 시작하면 처음에는 옛 지역에 있습니다. 새 세상은 시작 마을 근처에서 출발합니다. 기존 건축물을 유지하려면 이어서 탐험하세요.
- 생존/전투/제작 시스템은 이번 업데이트의 대상이 아니며 여전히 창작 탐험 모드입니다. 꽃 수집은 실제 수량 저장을 지원하지만 생존 인벤토리는 아닙니다.
- 개체는 청크 방문 시 시드에 따라 다시 생성됩니다. 개별 동물의 이동 위치와 행동을 영구 저장하지는 않습니다. 길이 막힌 NPC는 돌아서거나 점프를 시도하지만 복잡한 미로를 탐색하지는 않습니다.
- Greedy Meshing, Worker, 실제 GPU 인스턴싱, 완전한 투명 면 정렬, 장거리 지형 LOD는 아직 적용하지 않았습니다. 편집 기록은 보존해야 하므로 무한히 많은 블록을 수정하면 저장 용량은 증가합니다.

## 실제 검증

- 단위 검사 39개: 기존 물리 22개, 월드/호환성 10개, 모델/AI/환경 7개.
- 기존 브라우저 통합 21개와 기존 조작 회귀 11개를 실행했습니다. 회귀 스크립트는 비행 관성이 멈춘 뒤 클릭하도록 대기하고, Pointer Lock 중 클릭이 시선을 바꾸지 않게 마우스 down/up을 사용하도록 수정했습니다.
- 새 탐험 브라우저 검사 14개: 주민 생성/대화, 블록 편집, 실제 전진 비행과 복귀, 청크 언로드/재생성, 꽃 채집, 수집 UI, IndexedDB 재개/실제 레코드, 낮밤, 거리 설정, 오류 검사. 기록은 `tests/exploration-results.json`입니다.
- 전진 테스트에서 Z=92.5에서 약 -37.4까지 이동했고, 그 시점에 93개 청크가 생성되고 43개가 언로드되었습니다. 복귀 후 원래 청크가 다시 로드되며 파괴한 블록이 그대로 비어 있음을 확인했습니다.
- Chrome headless / ANGLE SwiftShader, 1280×720, 기본 80m 반경의 생성과 메시 작업 완료 후 115개 프레임 간격 샘플: 평균 약 60FPS, p95 16.7ms. 당시 97개 청크, 약 89만 정점, 69개 동물/주민을 관리했습니다. 이 수치는 해당 테스트 환경과 장면의 결과이며 모든 PC/지형에서 60FPS를 보장하지 않습니다.
- 최초 로딩이나 큰 파일 불러오기는 여전히 짧은 지연을 만들 수 있습니다. FPS가 낮으면 메뉴에서 렌더 거리를 48~64m로 낮출 수 있습니다.
