# 낮 17분 · 밤 4분 조정

## 기존 구조 분석

environment.js는 time을 초당 1씩 증가시켜 1200에서 순환했다. 태양 고도는 time/1200의 사인 곡선이므로 지평선 위·아래 시간이 각각 600초였다. game.js는 time을 JSON/IndexedDB에 그대로 저장하고, 같은 시각으로 하늘·태양·달·블록 조명·디버그 시계를 표시했다. 몬스터는 전역 하늘 밝기와 지형 높이 조건으로 생성되었다.

## 변경

- 저장된 time 범위 **0~1200**과 저장 포맷 v1/v2/v3를 유지한다. 0은 일출, 300은 정오, 600은 일몰, 900은 한밤중이다. 기존 시각을 새로 환산하거나 초기화하지 않는다.
- 낮 구간 0~600을 실제 **1020초**, 밤 구간 600~1200을 **240초** 동안 진행한다. 낮 속도는 초당 600/1020, 밤 속도는 초당 600/240이다. 한 주기는 **1260초**다.
- 시간 구간을 실제 경과 초로 변환해 증가시킨 뒤 다시 기존 시각으로 돌린다. 일몰·일출을 한 프레임 안에 넘거나 여러 날을 넘는 경우에도 각 구간 시간을 정확히 배분한다.
- 화면만 어둡게 바꾼 것이 아니라 환경 시계의 실제 진행 속도를 바꿨다. 환경 시계에는 물리 엔진의 0.25초 따라잡기 상한을 적용하지 않아 긴 프레임에도 하루가 느려지지 않는다. 물리·전투 시간과 조작은 기존 방식을 유지한다.
- 낮에는 밝은 푸른 하늘과 태양, 밤에는 어두운 하늘과 달을 표시한다. 지평선 근처의 주황색과 밝기는 smoothstep으로 연속 전환한다. 태양·달은 해당 지평선 근처 또는 위에 있을 때 그린다.
- 몬스터 생성 후보마다 하늘 밝기 × 지하 음영을 검사하며 **0.4 미만**에서만 생성한다. 지하 음영 함수는 실제 블록 면 렌더링과 공유한다. 낮의 어두운 동굴도 이 값으로 검사한다. 좀비·스켈레톤의 햇빛 피해도 같은 밝기 표본을 사용한다.
- 현재 조명은 기존 엔진의 주변광·지형 깊이 근사다. 이번 작업에 횃불 광원 전파·건물 지붕 그림자 시스템을 새로 구현한 것은 아니다.
- Esc·인벤토리·포커스 이탈에 따른 기존 일시정지는 유지한다. 다시 시작할 때 실제 날짜나 오프라인 경과 시간으로 세상 시간을 건너뛰지 않는다.

## 검증

전체 단위 검사 **80개 통과**. 이 중 새 주기 검사 6개와 실제 밝기 생성 검사 1개를 추가했다. 15/60/144FPS로 하루 전체 1260초를 시뮬레이션해 같은 시각으로 돌아오는 것을 확인했다. 낮·밤 경계 통과, 여러 날 누적, 메뉴에서 시각 불변, 기존 저장 시각 유지도 검사했다.

배포 HTML의 브라우저 검사 **10항목 통과**. 실제 실행 시 낮·밤 진행 비율, 450ms 렌더 지연에서도 시간 속도 유지, Esc 일시정지, IndexedDB 재접속, 인벤토리·블록 기록, WASD/E/Esc 조작, 밝은 지상 생성 금지와 어두운 지상 생성 허용을 확인했다. 콘솔 오류·pageerror는 0개였다. 결과는 tests/day-cycle-results.json에 있다.

태양·밝은 하늘과 달·어두운 하늘의 브라우저 캡처도 확인했다. 하루 21분을 사람이 실시간으로 기다리는 수동 플레이 검사는 하지 않았으며, 전체 주기는 단위 시뮬레이션과 실제 실행 속도 측정을 함께 사용해 검증했다.
